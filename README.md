## Em destaque

### Cyber Home Dashboard

Central local para acompanhar dispositivos autorizados da rede, saúde do notebook e conectividade da internet.

[![Cyber Home Dashboard](https://raw.githubusercontent.com/Cordeiro767/cyber-home-dashboard/main/docs/screenshots/dashboard-overview.png)](https://github.com/Cordeiro767/cyber-home-dashboard)

- Terminal seguro com comandos permitidos por allowlist
