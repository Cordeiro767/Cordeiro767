## Projeto em Destaque

### [Cyber Home Dashboard](https://github.com/Cordeiro767/cyber-home-dashboard)

**Local network monitoring dashboard built with FastAPI, SQLite, WebSocket and a cyberpunk-inspired UI.**

[![Cyber Home Dashboard preview](https://raw.githubusercontent.com/Cordeiro767/cyber-home-dashboard/main/docs/screenshots/dashboard-overview.png)](https://github.com/Cordeiro767/cyber-home-dashboard)

`FastAPI` `SQLite` `WebSocket` `psutil` `JavaScript` `Network Monitoring`

- Inventário de dispositivos separado por rede local.
- Topologia visual, eventos e monitoramento do notebook.
- Diagnósticos seguros baseados em allowlist, sem terminal livre.

**[Ver repositório](https://github.com/Cordeiro767/cyber-home-dashboard)** | **[Ver demo](https://github.com/Cordeiro767/cyber-home-dashboard/blob/main/docs/demo/dashboard-demo.webm)**
